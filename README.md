# ML Interview Questions

Банк вопросов с реальных технических собеседований на позиции Data Scientist, NLP- и LLM-инженер.

Связан с Telegram-каналом [maxouni.ai | by maxim ogorodnik](https://t.me/maxouniai). Кейсы по ML System Design — в соседнем сборнике [MLSD Cases](https://aimnoux.github.io/mlsd/).

**Сайт:** https://aimnoux.github.io/mlqa/
