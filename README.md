# ML Interview Questions

Банк вопросов с реальных технических собеседований на позиции Data Scientist, NLP- и LLM-инженер.

Связан с Telegram-каналом [maxouni.ai | by maxim ogorodnik](https://t.me/maxouniai).

**Сайт:** https://aimnoux.github.io/mlqa/

## Вопросы

Сейчас в банке **129 вопросов** с 8 собеседований. Вопросы отсортированы по встречаемости: 12 из них задавали больше одного раза.

| Тема             | Кол-во |
|------------------|--------|
| LLM              | 27     |
| AI-engineering   | 25     |
| Deep Learning    | 18     |
| Classic ML       | 14     |
| NLP              | 12     |
| MLOps и инфра    | 12     |
| Поведенческие    | 10     |
| Опыт             | 5      |
| Статистика       | 2      |
| ML System Design | 2      |
| Алгоритмы        | 2      |

Вопросы анонимизированы: без названий компаний, имён интервьюеров и деталей проектов кандидата.
